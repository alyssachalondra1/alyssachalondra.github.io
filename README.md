# Alyssa Chalondra Adimulyo — Portfolio

Personal portfolio website built with vanilla HTML, CSS, and JavaScript.
Deployed on GitHub Pages. Content is managed via a single `data.js` file.

## 🔧 Edit content
Open `data.js` and edit the `portfolioData` object. No build step required.

## 📁 Files
- `index.html` – page structure
- `style.css`  – styling (blue + yellow theme)
- `script.js`  – rendering & interactivity
- `data.js`    – all editable content (projects, skills, experience, etc.)
- `assets/`    – profile photo, CV PDF, project images

## ✉️ Contact form
Powered by EmailJS (free tier). Configure keys in `data.js → emailjs`.
